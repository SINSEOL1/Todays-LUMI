# 오늘의 루미 제품 기획

## 핵심 목적
게임 시작 시 채팅에 표시되는 LUMI 판매 안내를 화면에서 인식하고 이번 게임의 판매 아이템을 오버레이로 표시한다.

## 지원 판매 아이템

| 아이템 | 포인트 색 |
|---|---|
| 운석 | 남색 \`#405A86\` |
| 생명의 나무 | 녹색 \`#4C8A69\` |
| 미스릴 | 청록 \`#4C8997\` |
| 포스 코어 | 보라 \`#765B9D\` |

## UI 원칙
- 과한 그라데이션, 글로우, 유리 효과를 사용하지 않는다.
- 저채도 다크 UI를 기본으로 한다.
- 작은 라운드와 얇은 테두리를 사용한다.
- 게임 UI를 복제하지 않는다.
- 정보 표현을 우선하고 장식을 최소화한다.
- 메인 메뉴는 홈 / 오버레이 / 설정 / 정보의 4개로 유지한다.
- 첫 실행 온보딩 마법사를 만들지 않는다.

## 오버레이
- 항상 위
- 작업표시줄 및 Alt+Tab에서 제외
- 클릭 통과
- 게임 창 기준 상대 위치 저장 예정
- 기본 표시 시간: 경기 종료까지
- 기본형 / 컴팩트형 지원

## 프로그램 동작 원칙
- 게임 메모리 접근 없음
- 패킷 접근 없음
- DLL 인젝션 없음
- 게임 입력 자동화 없음
- 화면에 이미 출력된 정보만 처리
- 일반 동작에서 캡처 이미지를 디스크에 저장하지 않음
- OCR은 필요한 시간에만 수행하고 인식 완료 후 중단

## 설정
### 일반
- Windows 시작 시 실행: 기본 OFF
- 창을 닫으면 트레이로 최소화: 기본 ON

### 오버레이
- 오버레이 표시: 기본 ON
- 게임 활성화 시에만 표시: 기본 ON
- 위치/크기/투명도 저장
- 오버레이 테스트

### 인식
- 자동 인식: 기본 ON
- 채팅 영역 수동 재설정 기능 예정
- 인식 초기화 기능 예정

### 업데이트
- 자동 업데이트 확인: 기본 ON
- 게임 플레이 중 업데이트 팝업을 띄우지 않음
- GitHub Releases 기반

## 버전 규칙
\`A.B.C\`
- A: 대형 업데이트
- B: 일반 업데이트
- C: 버그 수정 및 소형 수정

B가 증가하면 C는 0으로 초기화하고, A가 증가하면 B와 C를 모두 0으로 초기화한다.
