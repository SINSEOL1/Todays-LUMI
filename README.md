# 오늘의 루미 (Today's LUMI)

이터널 리턴의 게임 시작 채팅에 표시되는 LUMI 판매 안내를 인식해, 이번 게임의 판매 아이템을 작은 오버레이로 보여주는 Windows 프로그램입니다.

> 오늘의 루미는 비공식 프로그램입니다.

## 현재 상태

개발 초기 단계입니다. 우선 앱 UI, 오버레이, 설정 저장, 트레이, 설치/업데이트 구조를 먼저 만들고 이후 실제 게임 화면 기반 인식 기능을 연결합니다.

## 판매 아이템

- 운석
- 생명의 나무
- 미스릴
- 포스 코어

## 원칙

- 게임 메모리 접근 없음
- 패킷 접근 없음
- DLL 인젝션 없음
- 게임 입력 자동화 없음
- 화면에 표시된 정보만 로컬에서 처리
- 일반 동작 중 캡처 이미지를 디스크에 저장하지 않음

## 버전 규칙

버전은 `A.B.C` 형식을 사용합니다.

- `A`: 대형 업데이트
- `B`: 일반 기능 업데이트
- `C`: 버그 수정 및 소형 변경

예: `1.0.0 → 1.0.1 → 1.1.0 → 2.0.0`
