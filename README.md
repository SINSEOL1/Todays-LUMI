# 오늘의 루미

이터널 리턴의 게임 시작 채팅에 표시되는 LUMI 판매 아이템을 인식해 오버레이로 보여주는 Windows 프로그램입니다.

> 오늘의 루미는 비공식 프로그램입니다.

## 기능

- LUMI 판매 아이템 자동 인식
- 운석 / 생명의 나무 / 미스릴 / 포스 코어 표시
- 오버레이 위치, 크기, 투명도 설정
- 인게임 단축키로 오버레이 표시/숨김
- 경기 종료 시 자동 숨김
- Windows 시작 시 실행
- GitHub Releases 기반 업데이트

## 다운로드

정식 배포본은 GitHub의 **Releases**에서 설치 파일을 받을 수 있습니다.

## 버전

버전은 `A.B.C` 형식을 사용합니다.

- `A`: 대형 업데이트
- `B`: 일반 업데이트
- `C`: 버그 수정 및 소형 변경
